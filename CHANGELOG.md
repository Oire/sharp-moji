# Changelog

All notable changes to SharpMoji are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Emoji data updates are additive and do not change the API, so a new Unicode release is a
**minor** bump. Major bumps are reserved for API changes. See
[docs/SPEC.md](docs/SPEC.md) section 7.3.

## [1.0.0] - 2026-09-18

First release. Emoji data for .NET 10, covering 28 languages, with everything embedded — no
network access and no file I/O.

### Added

- `EmojiCatalog` and `IEmojiCatalog`: immutable, per-language emoji data, cached and safe to
  share across threads. Construction is single-phase and the whole surface is synchronous,
  because the data is embedded and there is no I/O to await.
- Lookup by sequence, hexcode, shortcode or emoticon. Sequence lookup normalizes variation
  selectors, so the two spellings of an emoji — which look identical — resolve to one record.
- Localized labels, tags and category names in 28 languages, with canonical display ordering,
  groups and subgroups.
- `Search`: ranked, diacritic-insensitive search over labels, tags, shortcodes and emoticons,
  reporting why each result matched so a UI can group or highlight them.
- Skin-tone lookup — `GetSkinToneSlots`, `GetSkins` and `TryGetSkin` for one tone or two —
  covering the 19 emoji whose two people are toned independently. Matching tones resolve to the
  single-modifier variant, so a caller can pass every cell of a 5×5 grid without special cases.
- Shortcodes across seven presets, tolerant of the colons applications leave attached.
- `EmojiLocale`: every embedded language with its English and native names, baked in at build
  time so they do not depend on the host having ICU data.
- Trimming and NativeAOT support, with source-generated JSON throughout.

### Data

- Emoji data from [Emojibase](https://github.com/milesj/emojibase) 17.0.0 (Unicode emoji 17.0):
  1,949 emoji and 2,030 skin-tone variants per language.
- All 28 languages embedded in 1,419 KB, as one shared structure table plus per-language string
  tables — against 26.5 MB for 28 full copies.
- Regenerated by `scripts/update-emoji-data.ps1`, which prints a readable diff of what changed,
  since the packs themselves are compressed binary.

### Verified

- Conformance against Unicode's own `emoji-test.txt`, checked in both directions against the two
  published versions that can each answer one of them.
- A golden corpus of search cases across English, French, German, Ukrainian and Russian.
- Public API frozen with `PublicApiAnalyzers`.
- Builds, tests, trimmed publish and NativeAOT publish on Windows, macOS and Linux.

### Known gaps

- **Hebrew is not included.** CLDR has complete Hebrew emoji annotations, but Emojibase does not
  publish the locale; adding it upstream needs 120 category strings translated. See
  [docs/SPEC.md](docs/SPEC.md) section 14. This is additive, so it will land in a minor release.
- Search cannot rank by popularity. A query matching dozens of equally-tagged emoji ranks them by
  name length and canonical order, which is a heuristic rather than what people actually use most.
